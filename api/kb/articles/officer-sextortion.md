# First hour
- Acknowledge the case and send a reviewed reply with the safe actions.
- Check the evidence: handle, profile link, number, screenshots. The hash chain shows if anything changed.
- Check linked cases for the same handle or number.

# Referral
- Refer to Police CFPU and UCC through Habari. Include the case code, never the child's identity.
- Ask the platform for evidence preservation as soon as possible: deleted content may only be recoverable for a short time.

# Never
- Never contact the offender.
- Never ask the child to send the images again.
